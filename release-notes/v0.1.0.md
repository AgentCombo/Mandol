# Mandol v0.1.0

Mandol v0.1.0 is the first final-version PyPI release of the maintained Mandol
Python implementation. The project remains a research artifact and early
public release; it is not a production-ready service, and APIs may continue to
evolve during the `0.x` series.

## Highlights

- Public `MemoryUnit`, `MemorySpace`, `SemanticMap`, and `SemanticGraph` APIs.
- Dense, BM25, SPLADE, and graph retrieval with fusion and reranking.
- Hierarchical, entity-relation, and episodic triple-tower retrieval.
- Query routing, semantic quantification, and high-level memory construction.
- RocksDB-backed automatic tiered paging for cold payloads while retrieval
  indexes, UID mappings, MemorySpace membership, and graph topology remain
  resident.

## Release Scope

- `main` contains the maintained public Python implementation.
- `paper-repro` remains the frozen entry point for reproducing the paper's
  LoCoMo, LongMemEval, and performance results.
- Python `>=3.12,<3.13` is required. The supported package platform is Linux;
  the paper performance environment additionally depends on a compatible CUDA
  and flash-attention stack.
- Large datasets, generated graphs, model caches, and benchmark outputs are not
  distributed in the package.
- Full paper reproduction requires external model providers and local model
  downloads as documented in `paper-repro`.

## Changes Since 0.1.0a2

- Completed the RocksDB tiered-cache lifecycle, asynchronous eviction,
  page-in, snapshot, and close behavior used by the maintained runtime.
- Aligned package metadata, documentation, CI, website content, and citation
  information with the current public implementation.
- Added a PyPI-specific long description with absolute, tag-pinned image and
  documentation links.
- Changed release automation to build and validate tagged distributions without
  uploading them; PyPI publication remains a deliberate manual step.

No paper benchmark results, model roles, dataset splits, or evaluation settings
were changed for this release.

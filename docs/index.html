Mandol Documentation¶

This documentation tracks the current src/mandol package in this checkout. The maintained public surface is based on MemoryUnit, MemorySpace, SemanticMap, SemanticGraph, MultiRetriever and the retrieval-facing subpackages.

Historical pages from earlier architecture experiments are preserved under docs/archive/ for design provenance. They are excluded from the Sphinx build and are not an API contract for the current package.

Mandol 是什么？
===============

一句话版本
----------

Mandol 是一个让 AI 拥有「记忆」的系统。你把对话喂给它，它能自动理解、整理，之后你可以像问人一样用自然语言向它提问。

稍微长一点的版本
----------------

想象你有一个超级秘书：

- 你每天和不同人聊天、开会、讨论工作
- 秘书在旁默默记录，会后自动把重点整理成结构化的笔记
- 关键人物、重要事件、知识点，全都分门别类放好
- 你需要查什么，直接问「上周三和客户聊的报价是多少？」，秘书秒回

Mandol 就是这个秘书的 AI 版本。

它能做什么？
------------

- 记住对话、文档、任何文本信息
- 自动提取人物、地点、事件、知识点
- 理解「在家办公」和「远程办公」是同一个意思
- 跨越多段对话找到相关信息
- 按不同视角检索（知识视角、事件视角等）

它不能做什么？
--------------

- 不是 ChatBot，它本身不会和你聊天
- 不生成新内容，它只检索和整理已有的记忆
- 不替代数据库，它是记忆层，不是存储层

我该怎么开始？
--------------

最快的方式：前往 :doc:`five-minute-start`，复制粘贴代码，5 分钟跑通。

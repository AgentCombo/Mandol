# Archived Documentation

This directory preserves documentation from architecture experiments that
predate the current `src/mandol` package.

The archived pages may refer to removed interfaces such as `MemorySystem`,
`Uid`, `mandol.ports`, `mandol.domain`, `HybridRetriever`, and the former root
`config.yaml`. Their examples are not expected to run against the current
package and they are excluded from the Sphinx build.

Use the maintained documentation in [`docs/current`](../current/) and the
repository root README files for installation, API, and reproduction guidance.
Historical material is retained only for design provenance and should not be
used as an implementation contract.

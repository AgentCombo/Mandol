# API Reference

Comprehensive API documentation is available in the [Sphinx documentation](https://mandol.readthedocs.io).

## Core Components

- **MemorySystem** — Main entry point for memory operations
- **MemoryUnit** — Storage container for conversation data
- **SemanticGraph** — Entity-relationship graph
- **SemanticMap** — Vector store with hybrid retrieval
